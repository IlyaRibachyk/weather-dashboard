Обрано React 18 (підключення через CDN + Babel standalone, без npm/Vite).
Причина вибору: вже є попередній досвід роботи з React, тому знайомий синтаксис JSX та хуки (useState) дозволили швидше реалізувати компонентний підхід і зосередитись на самому завданні практикуму.
Додаткові переваги React у цьому контексті: явний однонаправлений потік даних (стан міняється лише через setState, а не прямою мутацією) робить менш імовірними випадкові розсинхронізації інтерфейсу з даними; значно ширша спільнота та більше готових прикладів/бібліотек, що корисно при подальшому вивченні.
