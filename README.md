### Перевірка на вразливі місця

Вразливе: список міст із сервера — назва міста виводилась через innerHTML. Виправлено на textContent.

Невразливі:

- Список збережених міст (форма додавання) — назва міста виводиться через textContent.
- Список збережених міст на окремій сторінці та деталі міста — назва й день виводяться через textContent.
- Картки прогнозу погоди — день, температура й опис виводяться через textContent.
- Інші місця з innerHTML лише очищують контейнер або вставляють статичний текст, написаний розробником, без даних користувача чи API.

### XSS

Тест: рядок `<img src=x onerror="alert('XSS')">` викликав alert через innerHTML. Після заміни на textContent рядок відображається як звичайний текст, без виконання.

### localStorage / IndexedDB

Сховище "cities" (IndexedDB) та "savedCities" (localStorage) містять лише назву міста, координати, температуру й опис погоди. Паролів, токенів чи персональних даних не виявлено.

### Секрети

Використовується публічний безкоштовний API Open-Meteo без ключа. Захардкоджених паролів чи токенів у коді немає.

### HTTPS

Розгортання на Vercel (HTTPS за замовчуванням).
